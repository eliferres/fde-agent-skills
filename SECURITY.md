# Security policy

## Reporting a problem

Use GitHub's private vulnerability reporting on this repository: open the Security tab and select "Report a vulnerability". Do not open a public issue for a security problem.

## What to expect

An acknowledgement within two business days. A confirmed problem gets a fix, a test that pins it, and a release, and the report is credited unless you ask otherwise.

## Scope

The scripts, installer, validator, and skill instructions in this repository. Issues in third-party agent runtimes belong to those runtimes.

## Supported versions

The newest release only. Older tags get no fixes.
